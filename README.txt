LAURENT CRM - prototipo locale
Per usare l’app su iPad, pubblicare index.html e manifest.webmanifest su un sito HTTPS (ad es. GitHub Pages), poi aprire in Safari e aggiungere alla schermata Home. Non aprire da anteprima File iOS: JavaScript potrebbe essere bloccato.
Attenzione: salvataggio locale per dispositivo, senza sincronizzazione cloud. Esportare backup JSON regolarmente. I dati importati richiedono verifica manuale.
